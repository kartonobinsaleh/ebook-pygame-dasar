Bab 1

Fondasi & Pergerakan Pemain

Di bab pertama ini, misi kita adalah membuat layar game bisa terbuka, tidak langsung menutup sendiri, dan membuat karakter utama kita (Si Papan Hijau) bisa bergerak ke kanan dan kiri.

1.1 Membuka Jendela Dunia (Game Window)

Setiap game butuh sebuah layar. Mari kita buat layar pertama kita! Coba ketik kode berikut di file main.py kamu:

File:main.py
python
import pygame

# 1. Inisialisasi Pygame
pygame.init()

# 2. Pengaturan Layar
SCREEN_WIDTH = 600
SCREEN_HEIGHT = 500
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("Bouncing Ball Catch")
  • pygame.init(): Wajib dipanggil pertama kali untuk menyalakan "mesin" gamenya.
  • set_mode(...): Mencetak jendela game sebesar 600x500 pixel.

Coba Jalankan (Run)! Apa yang terjadi?

Layar hitam akan muncul sekilas lalu langsung menghilang / tertutup sendiri! Mengapa demikian?

Ini karena program Python membaca kodemu dari atas ke bawah. Setelah sampai di baris terakhir, tugasnya dianggap selesai dan program langsung dimatikan.

1.2 Menambahkan Game Loop (Denyut Nadi Game)

Untuk mencegah jendela tertutup seketika, kita membutuhkan siklus Game Loop. Ini ibarat satpam yang selalu melek mengawasi interaksi pemain (seperti mengklik tombol silang merah).

Tambahkan kode berikut tepat di bawah kode sebelumnya:

python
# 3. GAME LOOP
running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
            
    pygame.display.flip()

# 4. Membersihkan program
pygame.quit()
  • event.type == pygame.QUIT: Ini yang mendeteksi saat kamu mengklik tombol silang merah ("X") di pojok jendela untuk menutup game.
  • pygame.display.flip(): Wajib ada! Berfungsi untuk me-refresh dan menampilkan gambar terbaru ke layar terus-menerus.
  • pygame.quit(): Bertugas mematikan mesin Pygame dengan aman agar jendela game tidak hang/crash saat ditutup.

Jalankan Sekali Lagi! Sekarang jendelanya akan terus terbuka dengan stabil. Mesin gamemu sudah hidup!

1.3 Mengecat Layar & Frame Rate

Sekarang kita punya layar, tapi warnanya masih hitam kelam. Mari kita beri warna Biru Gelap dan atur kecepatan game agar tidak terlalu ngebut.

Ketikkan kode yang di-highlight (ditandai biru) ke dalam file main.py kamu:

python
pygame.display.set_caption("Bouncing Ball Catch")

clock = pygame.time.Clock()
COLOR_DARK_BLUE = (30, 40, 60)
# GAME LOOP
running = True
while running:
    # ... 

    screen.fill(COLOR_DARK_BLUE)
    
    pygame.display.flip()

    clock.tick(60)
  • pygame.time.Clock() & clock.tick(60): Berfungsi membatasi kecepatan game agar maksimal berjalan di 60 Frame Per Second (FPS). Tanpa ini, komputermu akan memutar game ini terlalu cepat dan cepat panas!
  • screen.fill(COLOR_DARK_BLUE): Menghapus seluruh layar dengan warna baru setiap detiknya. Jika layar tidak dihapus, gambar lama akan membekas dan berbayang.

Coba Jalankan! Layarmu sekarang berwarna biru elegan, dan berjalan stabil di kecepatan 60 FPS!

1.4 Memunculkan Sang Pahlawan (Paddle)

Kita akan membuat papan (paddle) berwarna hijau di bagian bawah layar. Di game ini, koordinat X (kanan-kiri) dan Y (atas-bawah) sangat penting. Ingat, posisi (0,0) ada di ujung kiri atas layar!

Ketikkan kode yang di-highlight (ditandai biru) berikut ke dalam file main.py kamu:

python
# Pengaturan Warna (Red, Green, Blue)
COLOR_DARK_BLUE = (30, 40, 60)
COLOR_GREEN = (40, 200, 80)

player_width = 100
player_height = 20
player_x = (SCREEN_WIDTH - player_width) // 2
player_y = SCREEN_HEIGHT - player_height - 10
player_speed = 8

# GAME LOOP
running = True
while running:
    # ... (kode cek event klik X) ...

    screen.fill(COLOR_DARK_BLUE)
    
    # Gambar pemain (kotak hijau)
    pygame.draw.rect(screen, COLOR_GREEN, (player_x, player_y, player_width, player_height))
    
    pygame.display.flip()
    # ... (kode clock) ...
  • player_x = (SCREEN_WIDTH - player_width) // 2: Rumus pintar agar papan pemain otomatis berada tepat di tengah layar secara horizontal.
  • player_y = SCREEN_HEIGHT - player_height - 10: Ini menaruh papan pemain 10 pixel mengambang dari dasar layar terbawah (ingat, sumbu Y makin besar ke bawah!).
  • pygame.draw.rect(...): Fungsi sakti Pygame untuk menggambar persegi ke layar. Parameternya adalah (layar, warna, (x, y, lebar, tinggi)).

Coba Jalankan! Sekarang ada papan hijau cerah di bagian tengah-bawah layarmu. Pahlawan kita sudah lahir!

1.5 Bergerak Sesuai Perintah (Input Keyboard)

Pahlawan kita masih diam. Ayo buat dia bergerak ke kiri dan ke kanan menggunakan tombol panah di keyboard!

Ketikkan baris kode baru (yang di-highlight biru) di dalam Game Loop. Pastikan letaknya sebelum layar di-fill warna biru:

python
# GAME LOOP
running = True
while running:
    # ... (kode event X) ...

    keys = pygame.key.get_pressed()

    if keys[pygame.K_LEFT] and player_x > 0:
        player_x -= player_speed

    if keys[pygame.K_RIGHT] and player_x < SCREEN_WIDTH - player_width:
        player_x += player_speed

    screen.fill(COLOR_DARK_BLUE)
    # ... (kode draw.rect dan flip) ...
  • pygame.key.get_pressed(): Mengambil daftar status seluruh tombol keyboard (apakah sedang ditekan atau tidak).
  • keys[pygame.K_LEFT]: Mengecek apakah tombol "Panah Kiri" di keyboard sedang ditahan.
  • player_x -= player_speed: Mengurangi koordinat X pemain agar kotak bergeser ke kiri.
  • player_x > 0: Syarat agar pemain tidak menembus batas kiri layar. Posisi X harus selalu lebih besar dari 0! (Berlaku juga untuk batas layar sebelah kanan).

Hore! Bab pertama selesai dan kamu sudah punya pahlawan hijau yang bisa dikendalikan!

Bab 2

Memunculkan Bola & Deteksi Tabrakan

Di bab ini kita akan membuat musuh utama: Bola Merah yang memantul liar.

2.1 Menjatuhkan Bola Merah (Spawning)

Sama seperti saat membuat Pahlawan (Paddle), kita juga harus menyiapkan mesin pengacak, posisi awal, ukuran, dan menggambar bolanya di layar.

Ketikkan kode yang di-highlight (ditandai biru) ke dalam file main.py kamu:

python
import pygame
import random

# ... (kode inisialisasi & warna lain) ...

COLOR_RED = (230, 50, 50)
ball_size = 20
ball_x = SCREEN_WIDTH // 2
ball_y = 100
ball_speed_x = 4 * random.choice([-1, 1])
ball_speed_y = 4

# ... (kode posisi player) ...

running = True
while running:
    # ... (kode event & gerak keyboard) ...

    screen.fill(COLOR_DARK_BLUE)
    
    pygame.draw.ellipse(screen, COLOR_RED, (ball_x, ball_y, ball_size, ball_size))
    pygame.draw.rect(screen, COLOR_GREEN, (player_x, player_y, player_width, player_height))
    
    pygame.display.flip()
    # ...
  • import random: Memanggil alat pengacak dari Python.
  • random.choice([-1, 1]): Memilih acak arah awal bola (-1 berarti ke kiri, 1 berarti ke kanan) agar permainan selalu berbeda tiap dimainkan.
  • pygame.draw.ellipse(...): Fungsi untuk menggambar lingkaran/elips di layar.

2.2 Fisika Sederhana: Bergerak & Memantul di Dinding

Bola kita sudah tampil, tapi masih diam. Ayo buat bola tersebut jatuh ke bawah dan memantul tiap kali membentur tembok kiri, kanan, atau atap!

python
while running:
    # ... (kode event & gerak keyboard) ...

    ball_x += ball_speed_x
    ball_y += ball_speed_y

    if ball_x <= 0 or ball_x + ball_size >= SCREEN_WIDTH:
        ball_speed_x = -ball_speed_x

    if ball_y <= 0:
        ball_speed_y = -ball_speed_y

    screen.fill(COLOR_DARK_BLUE)
    # ...
  • ball_x += ball_speed_x: Membuat bola terus melaju tiap detiknya.
  • ball_speed_x = -ball_speed_x: Konsep Pantulan Fisika! Jika bola menabrak batas kiri (0) atau kanan layar, ubah kecepatannya menjadi berlawanan arah (dikali -1). Misalnya dari bergerak kiri (-4) menjadi kanan (+4).
  • Catatan: Kita sengaja TIDAK memantulkan bola jika menyentuh dinding bawah (lantai). Karena jika jatuh ke lantai, artinya bola luput dari tangkapan pahlawan kita (Game Over!).

2.3 Deteksi Tabrakan (Collision) dengan Pahlawan

Sekarang yang paling penting: membuat papan (Paddle) kita bisa "memukul" bola kembali ke atas agar tidak jatuh ke lantai.

python
while running:
    # ... (kode pantulan tembok) ...

    player_rect = pygame.Rect(player_x, player_y, player_width, player_height)
    ball_rect = pygame.Rect(ball_x, ball_y, ball_size, ball_size)

    if player_rect.colliderect(ball_rect):
        ball_speed_y = -abs(ball_speed_y)

    screen.fill(COLOR_DARK_BLUE)
    # ...
  • pygame.Rect(): Membuat kotak transparan ("ghaib") di sekitar Pahlawan dan Bola. Ini sangat berguna untuk sistem radar tabrakan di Pygame.
  • colliderect(): Fungsi ajaib! Langsung bernilai True jika kedua kotak saling bersentuhan. Kita tidak perlu meracik rumus matematika rumit!
  • -abs(ball_speed_y): Memastikan kecepatan bola selalu bernilai Negatif (terpantul ke atas layar). Menggunakan abs mencegah bug memantul berkali-kali di dalam papan.

Coba Jalankan! Sekarang kamu sudah bisa bermain tangkap-tangkapan bola menggunakan keyboard-mu!

Bab 3

Teks Skor, Game Over & Polishing

Game ini belum seru kalau tidak ada sistem skor dan menang kalah. Mari kita lengkapi gamenya!

3.1 Menghitung Skor (Sistem Hadiah)

Kita butuh sebuah variabel penyimpan skor, dan sebuah font (huruf) untuk menampilkannya ke layar.

python
# (Taruh di atas bersama warna)
font_score = pygame.font.SysFont("Arial", 28)
score = 0

# (DI DALAM GAME LOOP - Bagian Tabrakan)
if player_rect.colliderect(ball_rect):
    ball_speed_y = -abs(ball_speed_y)
    score += 10 # Tambah 10 poin!

    # Tambah ngebut sedikit biar makin seru
    if abs(ball_speed_y) < 12:
        ball_speed_y *= 1.05
        ball_speed_x *= 1.05

Penjelasan Detail:

  • pygame.font.SysFont: Memuat font "Arial" berukuran 28 yang sudah bawaan ada di sistem komputermu.
  • score += 10: Setiap kali terjadi colliderect (bola mengenai papan), nilai score ditambah 10.
  • *= 1.05: Setiap pantulan, kecepatan X dan Y bola dikalikan 1.05 (alias bertambah 5%). Ini membuat game makin lama makin sulit!

Lalu untuk menampilkannya ke layar, tambahkan di bagian bawah setelah kamu menggambar bola:

python
# Tampilkan Skor
score_text = font_score.render(f"Skor: {score}", True, COLOR_WHITE)
screen.blit(score_text, (15, 15))
  • render(...): Mengubah teks biasa menjadi sebuah gambar (surface) agar bisa ditempel di layar.
  • screen.blit(...): Ini adalah fungsi pygame untuk menempelkan gambar (atau teks yang sudah dirender tadi) ke layar. Kita tempel di koordinat X: 15, Y: 15 (Pojok Kiri Atas).

3.2 Kekalahan (Kondisi Game Over)

Kalau bola jatuh melebihi batas bawah layar, game harusnya berakhir.

python
# (Taruh di atas sebelum Game Loop)
game_over = False

# (DI DALAM GAME LOOP)
if ball_y > SCREEN_HEIGHT:
    game_over = True

Agar pemain dan bola berhenti bergerak saat Game Over, kita harus membungkus semua kode pergerakan di dalam if not game_over:. Jadi kalau game_over bernilai True, gerakan bola berhenti seketika.

3.3 Layar Game Over & Mulai Ulang

Saat kalah, kita munculkan teks besar di tengah layar dan meminta pemain menekan tombol SPACE untuk main lagi.

python
font_gameover = pygame.font.SysFont("Arial", 48, bold=True)

# (DI BAGIAN GAMBAR LAYAR / RENDER)
if not game_over:
    # (Kode gambar pemain & bola yang tadi)
else:
    go_text = font_gameover.render("GAME OVER!", True, COLOR_RED)
    restart_text = font_score.render("Tekan SPACE untuk Main Lagi", True, COLOR_WHITE)

    screen.blit(go_text, (SCREEN_WIDTH // 2 - go_text.get_width() // 2, 200))
    screen.blit(restart_text, (SCREEN_WIDTH // 2 - restart_text.get_width() // 2, 300))

Penjelasan Detail:

  • get_width(): Ini adalah trik pemrograman yang sangat cerdas! Fungsi ini menghitung panjang piksel dari sebuah teks sehingga kita bisa otomatis menaruh teks tersebut persis di tengah layar (Lebar Layar / 2 dikurangi Setengah Lebar Teks).
